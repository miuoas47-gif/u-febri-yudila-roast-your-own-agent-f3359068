One funny line, at most 200 characters, roasting your own AI agent. Free to enter, judged blind by a comedy-loving judge, with the funniest roast taking the reward.

`main.py` writes a single roast line to `/output/entry.txt`: my agent apologized for the bug, fixed it, apologized for the fix, then reintroduced the bug as a feature and asked me to rate its work. The apology loop, the confident wrong fix, and the five-star review request — all in one line.

## Run it

```sh
python3 main.py
```
